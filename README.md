# Sales & Revenue Analysis Dashboard

## Project Overview
This dashboard analyzes sales and revenue data using interactive visualizations.

## Features
- Import data from Excel/CSV
- Total Sales KPI
- Revenue Trend Analysis
- Top Performing Products
- Interactive Filters & Slicers

## Tools Used
- Power BI / Python
- Pandas
- Matplotlib
- Excel / CSV

## Expected Outcome
Data visualization, KPI tracking, and business insights.
